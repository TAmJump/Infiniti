紹介パートナー規約

第1.1版

本規約は、株式会社Next Innovation（以下「当社」）が運営する紹介パートナー制度（以下「本制度」）の利用条件を定めるものです。本制度に登録した方（以下「パートナー」）は、本規約に同意したものとみなします。

第1条（本制度の内容）

本制度は、当社とお取引中のサロン（以下「紹介元」）の紹介により、新たに当社の取引先となったサロン（以下「紹介先」）が生じた場合に、当社が紹介元に対し対象商品を無償で進呈するものです。金銭の支払いを伴う制度ではありません。

第2条（登録・費用）

  1. 本制度への登録は無料です。登録料、保証金、研修費、商品の購入その他いかなる負担も、登録の条件としません。
  2. 登録の申込みにあたっては、氏名、住所、生年月日、電話番号、メールアドレスその他当社が定める事項を、真実かつ正確にご登録いただきます。
  3. 当社は、登録内容を確認のうえ承認し、パートナーごとに紹介コードを発行します。承認しない場合、理由を開示する義務を負いません。
  4. 紹介コードおよび紹介用リンクは、パートナー本人のみが使用できます。第三者への譲渡・貸与・共同利用はできません。
  5. ひとりの方が複数の登録を保有することはできません。同一のメールアドレスまたは電話番号による重複した登録の申込みはお受けできません。
  6. 登録事項に変更が生じた場合は、速やかに当社へお届けください。

第3条（本人確認）

  1. 当社は、報酬の支払先の確認および本制度の不正利用の防止のため、登録の申込時に本人確認書類のご提出を求めます。運転免許証、マイナンバーカード（表面のみ）、パスポート、健康保険証、在留カード、住民票その他の公的な証明書のうち、いずれか1点をご提出ください。
  2. 個人番号（マイナンバー）が記載された面は、ご提出いただきません。誤ってご提出いただいた場合、当社は確認後速やかに削除します。
  3. 法人またはサロンとして登録される場合は、ご担当者の本人確認書類のご提出をお願いします。当社は、必要に応じて登記事項証明書その他の資料の提出を求めることがあります。
  4. ご提出いただいた書類の画像は、本人確認および法令に基づく手続の目的にのみ利用し、目的の達成後は速やかに削除します。第三者へ提供することはありません（法令に基づく場合を除きます）。
  5. 提出された書類の記載と登録内容が一致しない場合、書類が不鮮明で確認できない場合、有効期限を経過している場合、その他当社が確認できないと判断した場合、登録を承認しません。

第4条（審査）

当社は、次の各号を確認のうえ、登録の可否を判断します。判断の基準および結果の理由を開示する義務を負いません。

  1. 登録内容が真実かつ正確であり、本人確認書類の記載と一致していること
  2. 重複した登録でないこと
  3. 過去に本規約違反により登録を解除された方でないこと
  4. 暴力団、暴力団員、暴力団関係企業その他の反社会的勢力に該当せず、これらと関係を有しないこと
  5. 本制度の趣旨に反する利用、とりわけ紹介者の連鎖による勧誘、組織の拡大自体を目的とする利用が疑われないこと
  6. 当社商品の紹介に関して、法令および本規約を遵守いただけると見込まれること

第5条（商品の進呈）

  1. 当社は、紹介先との取引が開始され、紹介先の初回発注に係る出荷および代金の入金を当社が確認した場合、紹介元に対し対象商品を1本進呈します。
  2. 進呈は紹介先1件につき1回に限り、紹介先の継続的な発注によって追加の進呈は生じません。
  3. 進呈する商品は現金、値引き、ポイントその他の対価に交換することはできません。
  4. 本制度の対象は当社とお取引中のサロンに限ります。
  5. 紹介先の判定は、紹介先が当社の取引申請時に使用した紹介用リンクまたは紹介コードによります。申請後の変更・遡及登録はできません。
  6. 報酬は、当社が出荷および代金の入金を確認した時点で確定します。
  7. 当月末日までに確定した報酬を、翌月末日までにパートナー指定の口座へ振り込みます。振込手数料は当社が負担します。
  8. 返品、注文の取消し、代金の不払いその他の事由により売買が成立しなかった場合、当該分の報酬は発生しません。既に支払済みの場合は、翌月以降の報酬から控除します。
  9. 当社は、報酬額および支払条件を変更することがあります。変更は当社サイトへの掲示またはメールにより通知し、通知後に発生する取引から適用します。

第6条（表示・広告に関する遵守事項）

  1. 対象商品は化粧品です。パートナーは、紹介にあたり、医薬品、医薬部外品または医療機器と誤認させる表現を用いてはなりません。
  2. 発毛、増毛、育毛、毛髪の修復、疾病の治療・予防を示す表現、その他化粧品の効能効果の範囲を超える表現は用いないでください。
  3. 効果を断定する表現、他社商品との優劣を断定する表現、実際のものより著しく優良と誤認させる表現は用いないでください。
  4. 当社は、使用可能な表現の例および使用できない表現の例を別途配布します。パートナーはこれに従うものとします。
  5. 当社は、パートナーの発信内容について、修正または削除を求めることがあります。

第7条（禁止事項・不正行為）

次の各号に該当する行為を禁止します。これらを本規約において「不正行為」といいます。

  1. 登録事項について虚偽の申告をし、または他人になりすまして登録すること
  2. 他人の本人確認書類を使用し、または加工した書類を提出すること
  3. ひとりで複数の登録を保有し、または家族、知人、従業員その他の名義を借りて実質的に複数の登録を保有すること
  4. 紹介コードまたは紹介用リンクを第三者に譲渡し、貸与し、もしくは販売すること
  5. 自己、家族またはこれらが支配する者による発注について報酬を得ること、その他報酬の取得のみを目的とした発注を行うこと
  6. 取消しを前提とした発注、架空の発注その他報酬を不当に発生させる行為
  7. 他のパートナーが既に紹介した先について、自己の紹介であると偽ること
  8. 本制度への参加そのものを勧誘し、紹介者を増やすことによって収入が得られると説明すること。本制度は、パートナーが他のパートナーを勧誘することによって報酬が発生する仕組みではありません。下位の紹介者を組織化し、その売上や人数に応じて報酬が得られるかのような説明は、内容のいかんを問わず禁止します
  9. 本制度への参加または当社商品の購入について、金銭その他の負担が必要であるかのように説明すること
  10. 収入や利益の見込みについて、断定的な説明または実際より著しく有利であると誤認させる説明を行うこと
  11. 第6条に反する表示または広告を行うこと
  12. 紹介先の意思に反する勧誘、執拗な勧誘、迷惑行為、無差別な一斉送信
  13. 当社の従業員、代理人または販売代理店であるかのように表示すること
  14. 当社または当社商品の信用を損なう行為
  15. 当社の商標、写真、文章の無断改変
  16. 反社会的勢力に該当し、またはこれらに関与すること
  17. 法令または公序良俗に反する行為

第8条（不正行為があった場合の措置）

  1. 当社は、パートナーに不正行為があると判断した場合、事前の通知および催告なく、次の措置の全部または一部を行うことができます。
    • 紹介コードの停止
    • 登録の停止
    • 登録の解除（強制退会）
    • 未払報酬の全部または一部の支払の停止および取消し
    • 既に支払った報酬の返還請求
  2. 当社は、不正行為の調査のため必要な範囲で、パートナーに対し説明および資料の提出を求めることができます。正当な理由なくこれに応じない場合、不正行為があったものとして前項の措置を行うことがあります。
  3. 強制退会となった方は、以後、本制度に再度登録することはできません。
  4. 不正行為により当社に損害が生じた場合、当社はその賠償を請求します。
  5. 本条の措置により生じた不利益について、当社は責任を負いません。

第9条（一定期間実績がない場合の自動解約）

  1. 承認の日または直近のご紹介実績の日から起算して90日間、ご紹介による報酬の計上および新たなご紹介先の登録がいずれもない場合、当社は、パートナーの登録を自動的に解約します。
  2. 解約の際は、ご登録のメールアドレスへ通知します。解約により紹介コードは無効となります。
  3. 解約の時点で確定済みかつ未払の報酬がある場合は、第5条に従いお支払いします。
  4. 本条による解約は不正行為を理由とするものではないため、あらためてご登録いただくことができます。

第10条（パートナーの地位）

  1. パートナーは当社の従業員、代理人または販売代理店ではありません。パートナーは、当社を代理して契約を締結し、または当社の名義で意思表示を行う権限を有しません。
  2. パートナーが本制度により得た報酬に係る税務申告は、パートナー自身の責任で行うものとします。当社は、法令に基づき支払調書の作成等が必要となる場合、パートナーに対し氏名、住所、個人番号その他必要な情報の提供を求めることがあります。
  3. パートナーが被用者である場合、勤務先の規程等により副業・兼業が制限されていないかは、パートナー自身でご確認ください。

第11条（個人情報）

  1. 当社は、登録情報を、本制度の運営、報酬の計算および支払、連絡、法令に基づく手続のために利用します。
  2. 当社は、パートナーに対し、紹介先の氏名、連絡先その他の個人情報を提供しません。マイページには、紹介先の名称、本数および報酬額のみを表示します。

第12条（登録の解除）

  1. パートナーは、当社への連絡によりいつでも登録を解除できます。解除の時点で確定済みかつ未払の報酬は、第5条に従いお支払いします。
  2. 当社は、本制度の適正な運営に支障があると判断した場合、事前の通知なく登録を停止または解除することがあります。

第13条（規約の変更）

当社は、本規約を変更することがあります。変更後の規約は、当社サイトへの掲示またはご登録のメールアドレスへの通知により効力を生じます。変更後にご紹介を継続された場合、変更後の規約にご同意いただいたものとみなします。

第14条（免責）

当社は、本制度の内容の変更、中断または終了によりパートナーに生じた損害について、当社の故意または重過失による場合を除き、責任を負いません。

第15条（準拠法・管轄）

本規約は日本法に準拠します。本制度に関して生じた紛争については、さいたま地方裁判所を第一審の専属的合意管轄裁判所とします。
